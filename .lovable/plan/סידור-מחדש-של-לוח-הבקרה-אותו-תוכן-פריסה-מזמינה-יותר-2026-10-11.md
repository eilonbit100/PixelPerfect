# סידור מחדש של לוח הבקרה — אותו תוכן, פריסה מזמינה יותר

רק סידור ועיצוב. לא מוסיפים או מורידים נתונים, ולא משנים את החישובים.

## עובד — "היום שלי"

```text
+------------------------------------------------------------------+
| ערב טוב, יוסי · יום ראשון 11.10                    [+ תיעוד שיחה] |
| שורת סיכום אחת: 3 משימות להיום · 5 לידים במאגר · 2 מתעניינים     |
+-------------------------------------------+----------------------+
| הצעד הבא (עמודה ראשית)                    | ההתקדמות שלי (צד)    |
|  1. חשוב להיום — משימות ומעקבים להיום     |  הטיפול שלי היום     |
|  2. להמשיך עם מתעניינים | לקחת ליד חדש    |   לידים · מתעניינים  |
|     (לשוניות במקום שני חלונות צמודים)      |   · הפכו למנוי       |
|  3. לסגור בכרטיסי לקוחות (מקופל, עם מונה) |  הסגירות שלי          |
|                                           |   היום/שבוע/חודש     |
|                                           |  מה טיפלתי היום      |
|                                           |   (רשימה קצרה, 5 +)  |
+-------------------------------------------+----------------------+
```

- למעלה: ברכה + תאריך + שורת סיכום אחת של מונים (במקום ארבעה צ'יפים בתוך הכרטיס).
- עמודה ראשית = מה לעשות עכשיו, לפי סדר: חשוב להיום → מתעניינים/לידים חדשים (לשוניות, מתעניינים קודם) → כרטיסים להשלמה.
- עמודת צד צרה = ההישגים שלי: הטיפול היום, הסגירות, ורשימת "מה טיפלתי היום" מקוצרת עם "הצג הכל".
- כשאין משימות להיום — מוצגת הזמנה ידידותית "זמן מצוין לקחת ליד חדש" שפותחת ישר את לשונית הלידים.
- כל שורה: שם, שורת מידע אחת, כפתור פעולה ברור ("להתקשר" / "להמשיך" / "להשלים"). צבעים רגועים, אדום רק לאיחור.

## מנהל סניף ומטה

```text
+------------------------------------------------------------------+
| ברכה · סניף            | שורת מדדים (ManagerStrip / KPI למטה)    |
+-------------------------------------------+----------------------+
| לביצוע היום (תובנות קריטיות)              | ממתינים לאישור       |
| מעקב לידים ומתעניינים                     | המשימות שלי להיום    |
| הצוות שלי | לקוחות חסומים (שני טורים)      | שאל את המערכת        |
| מלאי חכם                                  |                      |
| תוכנית יומית · דורש טיפול (פחות דחוף)     |                      |
+-------------------------------------------+----------------------+
| השוואת סניפים (מטה, כל הארגון בלבד)                               |
+------------------------------------------------------------------+
```

- היום הכל נערם בעמודה אחת ואז מתחת עוד אזור עם צד. מאחדים לפריסה אחת עם עמודת צד קבועה מההתחלה.
- הדחוף ביותר (תובנות קריטיות) עולה לראש; "דורש טיפול" הפחות דחוף יורד לסוף.
- ממתינים לאישור, המשימות שלי והעוזר עוברים לצד כבר מהשורה הראשונה.
